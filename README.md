# HotelDatabase
# Sistema de Gerenciamento Hoteleiro

Projeto de banco de dados desenvolvido em SQL/MariaDB para gerenciamento de um hotel e feito um PHP para melhor inserção de dados, 
para o controle de:

- Reservas
- Quartos
- Funcionários
- Clientes
- Check-in e Check-out
- Hóspedes
- Consumos
- Telefones e endereços

---

# Tecnologias Utilizadas

- SQL
- MariaDB
- MySQL Workbench
- Apache
- PHP

---

# Estrutura do Projeto

O banco de dados possui as seguintes entidades principais:

## Reservas
- Tipo de reserva
- Dados da reserva
- Relacionamento com cliente e funcionário

## Quartos
- Tipos de quarto
- Status do quarto
- Controle de ocupação

## Funcionários
- Departamentos
- Cargos
- Dados cadastrais
- Telefones
- Endereços

## Clientes
- Pessoa Física
- Pessoa Jurídica
- Telefones
- Endereços

## Hospedagem
- Check-in
- Check-out
- Hóspedes
- Consumos


# Objetivo do Projeto

Este projeto foi desenvolvido com fins acadêmicos para praticar:

- Modelagem relacional
- Integridade referencial
- Normalização
- Constraints
- Relacionamentos em SQL
- Estruturação de banco de dados
